## Read it before you install it

A skill is a page of instructions your AI will follow. Don't install one you haven't read, mine included. These are plain text, with no programs inside.

## Install

You need a computer with Claude Code or Codex. Copy this and send it to your AI:

```
Install the skill at https://github.com/aiworkhabits/skills/tree/main/skills/done into my personal skills folder so I can use it in every project. Read the whole file first and tell me in plain words what it does. If I already have a skill called done, stop and ask me before you replace anything. When it's in, tell me how to run it.
```
